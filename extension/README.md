安装（Chrome / Microsoft Edge 桌面版）
1. 下载 ZIP 后全部解压到固定文件夹。不要删除或移动此文件夹。
2. 在 Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择含 manifest.json 的文件夹。
5. 在同一个浏览器打开 https://cs2-radar-lab.moaniq12.chatgpt.site/ 并刷新。
6. 页面显示“扩展已连接”后粘贴 HLTV 链接，点击导入。

如果网站需要登录，请使用拥有此网站访问权限的账号。
Codex 内置浏览器不是扩展的安装目标；请在安装扩展的 Chrome / Edge 使用网站。
可用范围：比赛详情、赛事详情、带 event= 的赛事选手统计。
整届赛事先读取选手列表，选择选手后继续打开该选手的赛事统计页。
遇到 HLTV 验证需要你在 HLTV 页面完成，最长等待 3 分钟。
读取完成后回到网站即可查看。不要在读取途中修改 HLTV 筛选或页面阵营。
扩展只读取 HLTV 页面统计并发回指定网站，不读取 Cookie、密码或其他网站。
扩展不能保证 HLTV 所有页面结构均可识别；失败会提示，不会伪造数据。
更新时用新 ZIP 内容替换扩展文件夹，然后在扩展管理页点击重新加载并刷新网站。
